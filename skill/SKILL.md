# 科学边界 Science Frontier

## 用途

当用户想了解当前世界科学最前沿的问题和研究方向时，使用本技能。覆盖10大领域、109个前沿科学问题，每个问题包含描述、当前进展、关键研究方向、影响力评级和关联问题。

## 数据

技能数据存储在 `references/frontier-data.json`，包含109条记录，每条字段：

| 字段 | 说明 |
|------|------|
| id | 唯一标识 (如 PHY-001) |
| domain | 大领域 (10个) |
| subdomain | 子领域 |
| title | 问题名称 |
| description | 问题描述 |
| current_state | 当前研究进展 |
| key_directions | 关键研究方向 (数组) |
| impact | 影响力 1-5 |
| difficulty | 难度 1-5 |
| timeline | 预计突破时间线 |
| related | 关联问题ID (数组) |
| sources | 信息来源 (数组) |

## 查询模式

### 模式1: 领域浏览
用户说 "物理学前沿" / "生命科学在搞什么" / "量子计算前沿"
→ 读取该领域所有问题，返回摘要列表（标题 + 影响力 + 一句话描述），按影响力排序。

### 模式2: 深度追问
用户说 "暗物质本质是什么" / "室温超导离实现还有多远" / "详细说说AGI对齐"
→ 读取该问题的完整数据（description + current_state + key_directions），返回结构化深度解答。

### 模式3: 跨领域关联
用户说 "哪些问题跟AI有关" / "量子计算关联哪些领域" / "给我看关联网络"
→ 搜索所有问题，找出 related 字段中包含相关ID的问题，返回跨领域关联列表。

### 模式4: 探索引导
用户说 "随便看看" / "最值得关注的问题" / "给我推荐几个"
→ 返回影响力5分的问题列表（约30+个），按领域分组，每个附带一句话亮点。

### 模式5: 排行/筛选
用户说 "最难的问题" / "最近能突破的" / "影响力最高的"
→ 按 difficulty/timeline/impact 排序返回 TOP 10。

## 输出规范

1. **领域浏览**：用表格或列表，每条一行（标题 + 影响力★ + 时间线）
2. **深度追问**：分"问题描述"→"当前进展"→"关键方向"三段，用emoji图标分隔
3. **跨领域关联**：用分组列表，标注每个问题所属领域
4. **探索引导**：按领域分组，每个问题一句话亮点
5. **排行/筛选**：用表格，包含排名、标题、领域、评级

## 注意事项

- 数据最后更新于 2026-07，回答时提示用户关注最新进展
- 涉及时间线预测时，强调这是估计值
- 鼓励用户追问：在回答末尾可建议"想深入了解哪个问题？或者看看关联领域？"
- 如果用户问的问题不在数据库中，用自身知识补充并提示"这不在当前数据库中，以下是本神人的知识补充"
