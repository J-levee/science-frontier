# 科学边界 · Science Frontier

> **仰望·追问·探索** —— 把 109 道未解之题变成星图，给乡村孩子一张可触摸的科学边界。

## 🌟 这是什么

「科学边界」是一个为 **10-16 岁乡村/山区学生** 打造的科普知识星图。我们把 1479 位获奖者的知识成果组织成一张**交互式科学叙事页**，让孩子用手机就能探索前沿科学——从暗物质到量子计算，从挂谷猜想到可控核聚变。

**在线体验**：https://j-levee.github.io/science-frontier/

## ✨ 核心能力

| 能力 | 说明 |
|---|---|
| 🗺️ **知识星图** | 109 个前沿问题映射为闪烁的星点，10 个领域用不同色光编码 |
| 👤 **探索者星系** | 1479 位获奖者（含诺贝尔/菲尔兹/图灵/沃尔夫/邵逸夫等 23 项目） |
| 🔍 **100% 溯源** | 每条获奖词/问题描述都有官方权威来源链接，点开即刻验证 |
| 💬 **AI 问不倒** | 嵌入百炼大模型，随时向 AI 提问——精选问题一键发送，也支持自定义 |
| 📱 **手机即看** | 响应式设计，乡村学校的一部手机就能完整浏览 |
| 📖 **深度科普** | 6 大热点方向图文专题，含 SVG 图解 + 生动比喻 + 音频播客 |

## 🎨 视觉叙事：5 屏沉浸式

1. **仰望** —— 英雄屏，109 个问题悬浮如星空
2. **边界** —— 知识边界线，星星按「已知 / 远方 / 未知」分布
3. **星系** —— 三体 N 体引力模拟，10 颗行星围绕 3 颗恒星
4. **归宿** —— 星光坠落人间，21 位代表获奖者肖像 + 光束降临
5. **启程** —— 3 条学习路径 + 10 个领域探索卡 + 教学指南

## 💡 为什么做

乡村学校里，一个 12 岁的孩子可能从未听说过"量子纠缠"或"暗物质"。不是因为他们不聪明，而是因为缺少**能听懂的方式**。

「科学边界」把最前沿的科学问题变成星星、变成故事、变成可以追问的对话。它不要求任何安装、不依赖任何配置——打开浏览器就行。

## 🚀 跑起来

```bash
# 方式一：直接打开
open design-proposal-v11.html

# 方式二：本地服务
cd 科学边界项目
python -m http.server 8767
# 浏览器打开 http://127.0.0.1:8767/design-proposal-v11.html
```
