jsdom 验证、数据校验、回归清单目前只存在于对话记忆（#22 前端动效、P4 讲解层验证记录），**未成文**。

## 目标读者

- 实施 Agent（改动后自测）

## 必须包含的章节
1. **前端冒烟测试**（jsdom）：
   - 加载 `index.html` 无 JS 运行时错误
   - 领域卡片渲染数 = 10；问题列表渲染数符合筛选
   - 溯源链接（`srcLinks`）数与 `sources` 数一致
   - 荣誉星图板块（TEMP 或重构后）渲染卡片数 > 0
2. **数据校验**：
   - `awards-data.js`：条数 = 1482、Wikidata 富化率 = 100%、`star`/`domain` 枚举合法、`year` 区间合理
   - `frontier-data.*`：109 条、溯源率 = 100%（每条 ≥1 source）
3. **回归清单（叙事核心不可破）**：
   - 5 色语义变量存在且被使用
   - 100% 溯源锚文案与链接完整
   - 三体星系（3 恒星 + 7 行星）结构不被破坏
   - 知识星座/关联网络可打开
4. **讲解页验证**：3 个讲解页（fusion/ai-alignment/kakeya）零 JS 错误，`cards` 数与 `srcLinks` 数符合预期。
5. **CI 建议（可选）**：把上述校验脚本接入提交前检查。

## 验收标准
- 每次生产改动后，有**可一键执行**的验证脚本与明确通过阈值。
- 回归清单任一项失败即阻断合并。
