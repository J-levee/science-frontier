# 科学边界 · 视觉叙事方案

> 目标:让内容从「数据库浏览器」升级为「品牌故事」,用视觉元素更好地讲述科学边界的品牌叙事。
> 现状文件:`science-frontier/website/index.html`(483KB 自包含单文件,深空科幻质感)

## 一、诊断:现在的视觉只装饰,不叙事

| 维度 | 现状 | 问题 |
|------|------|------|
| 信息架构 | 领域总览 → 列表 → 详情 → 网络 | 工具逻辑,读者一秒变"查库的人",无情感钩子 |
| 视觉角色 | 星空/星云/栅格 | 只是背景壁纸,未成为隐喻系统 |
| 最强资产 | 109/109 全溯源、179 条关联连线 | 被埋成详情页 / 孤立工具页,未前置 |
| 角色与弧线 | 无 | 读者是旁观者,无"陪伴感" |

底层内容其实扎实:109 个前沿问题、10 个领域、每条带 `impact`/`difficulty`/`timeline`/`related`/`sources`。

## 二、故事内核(Story Spine)

- **曾经**:人类以为世界有边界(地平说、原子不可分、光速极限)…
- **每天**:科学家在 10 个领域、109 个最前沿问题上,不断推进这条边界
- **直到**:你(读者)点开,成为"边界上的人"
- **所以**:每个问题都是一扇门,每条连线都是已知与未知的桥

**品牌主张(建议)**:「站在已知的边缘,眺望未知的星海」(The edge of knowing.)

**情感弧**:敬畏(Awe)→ 好奇(Curiosity)→ 联结(Connection)→ 归属(Belonging)→ 行动(Action)

## 三、视觉语言系统

### 3.1 配色语义化(复用现有 5 色,赋予叙事含义)

| 语义 | 现有色值 | 叙事角色 |
|------|---------|---------|
| 已知 / 探索 | 靛蓝紫 `#6366f1` | 主叙事色,领域、探索状态 |
| 关联 / 桥接 | 青 `#06b6d4` | 连线、知识星座、跨领域关系 |
| 突破 / 影响力 | 暖橙 `#f59e0b` | 高影响力问题、里程碑 |
| 高难 / 未解 | 红 `#ef4444` | 高难度、尚未突破的问题 |
| 可信 / 溯源 | 绿 `#10b981` | 已溯源来源、信任背书 |

### 3.2 图形隐喻(把装饰升级成语言)

- **边界线 Boundary**:横贯 hero 的「已知 / 未知」发光分隔线,问题漂浮两侧。
- **知识星座 Constellation**:关联网络中节点=星、连线=光、领域=星座群(直接叙事化现有 D3 力导向图)。
- **探针 Probe**:hover/选中问题时,从边界线射出一道光连到该问题(动效叙事)。

## 四、页面级五幕重排(现有零件重组装,非推倒)

1. **第一幕·钩子**:hero 改造——命题大字 + 边界线 + 三核心数字(109 问题 / 10 领域 / 全溯源)。
2. **第二幕·领域星系**:「领域总览」升级为按规模/热度排布的星座群,hover 浮现该领域一个灵魂问题。
3. **第三幕·问题深潜**:现有列表+详情,卡片用语义色标注影响力/难度/时间线。
4. **第四幕·知识星座**:现有「关联网络」升级为叙事高潮,可按领域聚焦某星座。
5. **第五幕·信任锚 + 召唤**:新增——109/109 全溯源做信任背书 + 「成为边界上的人」(订阅/探索/分享)。

## 五、落地路线图
