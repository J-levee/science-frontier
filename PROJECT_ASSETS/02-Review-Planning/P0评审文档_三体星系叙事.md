## 0. 已确认决策（用户拍板）
- **①B**：三体 = 物理（物之理）/ 生命（存在与演化）/ 计算（形式与智能）
- **②通过**：其余 7 领域做成绕三体的 7 颗行星，每颗主受一颗恒星引力、被另两颗微牵引
- **③通过**：探索者 = 可自由穿梭领域的「水滴探测器」（非静态第 8 行星）
- **④范围**：先收**科学诺奖 + 策展 Top 研究者**；**数据后续补全**（本次仅脚手架，不拉 API）

## 1. P0 目标
把「三体星系」叙事骨架低风险落地到 `index.html`，让首页从「数据库浏览器」变成「有钩子、有世界观、有信任背书」的叙事入口。**不推翻现有结构**，只重排/增强已有零件。

## 2. 改动清单（本次评审范围，共 5 项）

### 2.1 Hero 钩子改造
- **位置**：`index.html` 第 196–206 行（`<div class="hero">` 块）
- **改什么**：
  - 主标 `<h1>` 改为命题大字：**「站在已知的边缘，眺望未知的星海」**；副标保留「当前世界最前沿的科学问题与探究方向」
  - hero 内新增一条**动态绘制的边界线 SVG**（`stroke-dasharray` + `stroke-dashoffset` 动画，克制、沿用三体式质感），寓意「已知/未知分界」
  - 星空背景已有，加轻微渐显动效（可选，不抢戏）
- **验收**：首页首屏出现命题大字 + 一条可见的边界线；动效不卡顿

### 2.2 溯源率前置 → 信任锚
- **位置**：第 204 行 `stat-traced`（当前写死 `0%`，是 bug）+ 第 286 行附近 `tracedEl` 逻辑
- **改什么**：
  - `stat-traced` 改为 JS 动态计算真实溯源率（109/109 = 100%），不再写死 0%
  - hero 内新增**诺奖信任锚区块**：文案「诺奖荣誉星图 · 即将收录」（占位，**不显示虚构数字**，因数据后续补全）
  - 预留 `laureates` 占位数组（空或 2–3 条 seed 示例），供 P1 填充
- **验收**：溯源率显示真实 100%；诺奖区块显示占位文案、无假数据

### 2.3 配色语义化
- **位置**：第 9–15 行 `:root` 变量区（**不改色值**，仅补语义注释 + 映射）
- **改什么**：在现有 `--warm/--hot/--cool/--green/--accent` 上明确叙事角色，并在卡片渲染处按字段着色：
  | 变量 | 色值 | 语义角色 |
  |------|------|----------|
  | `--accent` | #6366f1 | 已知/探索（主叙事色） |
  | `--cool` | #06b6d4 | 关联/桥接/时间线 |
  | `--warm` | #f59e0b | 突破/影响力 |
  | `--hot` | #ef4444 | 高难/未解 |
  | `--green` | #10b981 | 可信/溯源 |
  - 领域卡片的影响力/难度用 `--warm`/`--hot` 区分；时间线用 `--cool`
- **验收**：颜色含义统一，旧卡片样式不被破坏（用变量隔离，不硬编码新色）

### 2.4 领域总览 → 三体星系
- **位置**：第 207 行 `domain-grid` 容器 + 第 314–360 行 `renderHome()`（原网格逻辑）
- **改什么**：
  - 新增 `renderGalaxy()` 函数（约 +80 行），用**已内联的 D3 力导向**（复用 `showNetwork` 的 D3）把 10 领域渲染为 **3 恒星 + 7 行星**：
    - 恒星：物理学(#818cf8) / 生命科学(#10b981) / 数学与计算(#f59e0b)
    - 行星（按已批准映射）：
      - 物理系：宇宙学(#06b6d4)、材料与能源(#a78bfa)、航天与太空探索(#38bdf8)
      - 生命系：地球科学与气候(#84cc16)、化学(#f97316)
      - 计算系：信息与智能(#ec4899)、社会科学与认知(#e879f9)
  - 每颗天体 hover 浮现该领域「一个灵魂问题」（从 DATA 的 `current_state`/`key_directions` 抠一句）
  - 点击天体 → 调已有 `showDomain(name)` 进入列表（逻辑不变）
  - 原 `renderHome` 网格逻辑**保留为 `renderHomeGrid` 副本**，作为窄屏(<768px)回退（复用第 110 行 media query）
- **验收**：总览视图呈星系布局；3 恒星 + 7 行星可见；hover 出灵魂问题；点击进列表；窄屏自动回退网格

### 2.5 水滴探测器（读者视角）
- **位置**：星系视图内新增（CSS + 轻量 JS，约 +30 行）
- **改什么**：
  - 鼠标在星系视图内移动时，跟随一个「水滴」小图标（SVG，致敬小说意象；内部母题，对外命名需注意品牌合规）
  - hover 某天体时，水滴射出一道探针光（SVG 直线/CSS），连到该天体，强化「你正探索」
  - 不强制 D3，用绝对定位 + SVG 线即可，性能可控
- **验收**：水滴跟随光标；hover 天体时有探针光连线；不报错
